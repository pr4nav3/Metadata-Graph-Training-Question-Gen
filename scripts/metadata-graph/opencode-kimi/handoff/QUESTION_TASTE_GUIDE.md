# Question Taste Guide

Good questions are human-shaped. They sound like a lawyer, compliance officer,
investor, journalist, or analyst arrived with a practical confusion.

The purpose is to teach SEBI-document memory across the corpus, so prefer
difficult, evidence-grounded questions that add a real memorization target over
questions that are merely novel.

## What Good Looks Like

A strong question usually asks for one of these:

- applied compliance judgment
- current rule after amendments
- proposal versus final rule
- version delta and consequence
- current scope or eligibility
- deadline or effective-date trap
- threshold or exception trap
- approval authority
- amount reconciliation
- cost or burden allocation
- scope exclusion
- procedural timeline or remedy
- entity or role disambiguation
- practical checklist across role + certification + filing requirement
- lineage across filings, circulars, orders, or notices
- absence/non-implementation check
- count/filter across a defined corpus slice
- investor-facing comparison of instrument terms

The evidence may be technical, but the user need should be natural.

## Taste Test

Ask: would someone plausibly ask this before knowing the exact source documents?
Does the answer need multiple documents to resolve a decision, classification,
amount, deadline, next step, or practical understanding?

Prefer one clear axis and one answer shape. Do not make a weak question stronger
by stacking clauses. A difficult question can be short.

## Comparison Questions

Comparisons are good when the axis matters. Bad comparison questions merely ask
the model to summarize two documents side by side. Good ones ask what changes
for a person, entity, obligation, remedy, amount, timeline, exception, or legal
consequence.

## Multi-Doc Necessity

Each final question must truly require at least two documents. If removing one
cited document leaves the answer basically intact, the question is not
multi-document enough.

The second document should not be mere background, existence confirmation, or a
repeated fact.

## Reviewer Calibration

Separate factual correctness from dataset worthiness. A question can be accurate
but still need revision if the second document is weak, the wording is legal
exam-shaped, or the same practical answer is already covered.

Do not reject solely because two questions use the same docs, chunks, or broad
frame. Similarity is acceptable when the question teaches a distinct
memorization target: a different rule condition, exception, date, actor, amount,
approval authority, procedural step, document lineage, or factual pattern.
Reject when the later question would not add a meaningful memorization target
beyond an already accepted question.

Do not default to the same few comfortable question shapes. Use the frame the
evidence naturally supports, and vary the frame when the evidence supports a
different user need.
